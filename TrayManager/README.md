# 托盘管理

个人制作的轻量 Windows 11 托盘工具，WinUI 3 / Mica / 圆角卡片，随系统切换深浅色。

> 这是我根据个人审美和使用习惯制作的实验性工具，不是 Microsoft、Windows 或 PowerToys 的官方项目，也不代表相关软件官方。不太建议其他人直接用于日常环境；优先使用 Windows 或对应应用自带的官方设置。本工具不能保证兼容所有程序和未来的 Windows 更新。

## 使用

- 解压后运行 TrayManager.exe；或在 PowerShell 中运行 Install.ps1，安装到当前用户目录并创建开始菜单入口。
- 开关开启表示本工具持续隐藏该图标。应用和后台服务不会停止。
- 每 5 秒重新核对实时图标，并重新应用隐藏规则。搜索、刷新列表均在窗口内操作。
- 已隐藏图标会保存进程启动时间和窗口身份，避免隐藏后从列表消失。无法重新定位的旧规则会单独列出，可手动移除。
- 双击本程序托盘图标打开窗口，没有右键菜单。可以隐藏本程序图标；再次启动程序会唤回同一个窗口。
- 关闭窗口只是收起。“退出程序”恢复本次由工具隐藏的图标；保存的规则在下次启动时继续生效。
- “恢复本工具隐藏的图标”会清除相关规则。不修改其他应用的启动方式、设置和系统托盘排序。
- 默认不设置开机启动，也不需要管理员权限。

## 兼容性和限制

需要 Windows 11 x64、.NET 10 Runtime 和 Windows App Runtime 2。采用共享运行库以减少分发体积，并非零依赖单文件；其他电脑需要自行安装这些官方依赖。

通过通知区域缓存发现候选项，再使用 Shell_NotifyIconGetRect 核验实时身份；非 GUID 图标还须核对进程路径、窗口和 UID。无法安全定位的项目不会列出，列表不是所有系统图标的完整枚举。

开关表示本工具的规则，不表示图标原本是否隐藏。Windows 没有公开接口读取所有图标的隐藏状态。请勿对已由其他工具隐藏的图标重复管理，否则“恢复”可能使它重新显示。

应用重建图标后，下一次轮询才会再次隐藏，期间可能短暂出现。系统升级可能改变兼容性。异常结束进程时来不及恢复图标，可重新启动本工具后点击恢复，或重启对应应用。

设置：%LOCALAPPDATA%\Tomclanc\TrayManager\settings.json。当前没有正式卸载器，也没有卸载时自动恢复功能。卸载前先在窗口中点击“退出程序”，程序会尝试恢复本次由它隐藏的图标，再删除安装目录和开始菜单快捷方式；设置文件可以保留。直接删除文件夹或强制结束进程不能保证恢复。无法定位的图标可通过重启对应应用恢复。

## 构建

安装 .NET 10 SDK 后执行 `./Build.ps1`，生成 x64 程序目录及 ZIP。图标由脚本绘制，无外部图片依赖。
